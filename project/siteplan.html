Coastal Travel Guide

Site Name

Site Name: Coastal Travel Guide

This name was chosen because it represents a travel website focused on coastal destinations, travel tips, and exploration guides for beaches and ocean regions.

Optional Domain: coastaltravelguide.com

Site Purpose

The purpose of this site is to provide travel information about coastal destinations. It will include destination guides, travel tips, and recommendations for beach trips.

Scenarios

  • What are the best coastal destinations for affordable vacations?
  • What should I pack for a beach trip in different seasons?

Color Schema

Primary Color: #1e3a5f (used for headers, headings, and footer background)

Accent Color: #f4a261 (used for highlights, buttons, and design accents)

These colors were selected to create a calm ocean-inspired theme representing coastal travel.

Typography

Headings: Georgia, serif

Body Text: Arial, sans-serif

Georgia is used for headings to give a more elegant travel-magazine style appearance, while Arial is used for readability in paragraphs and general content.
